# Eve Conversation Screen Spec

Mobile-first portrait.

Hierarchy:
1. Header: Listen with Eve + settings
2. Large Eve avatar
3. Conversation state pill
4. Scrollable messages
5. Rounded message composer
6. Microphone control integrated into composer
7. Send control

Visual behavior:
- Idle: quiet neutral Eve
- Listening: gentle scale/glow + Listening label
- Processing: soft glow + Thinking label
- Speaking: stronger glow + Speaking label
- Error: warning state with retry

The static image is temporary. The Rive avatar should occupy the exact same visual slot later.
